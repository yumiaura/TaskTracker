# TaskTracker

A task board Claude fills in for itself.

Claude Code already keeps a todo list while it works, and that list disappears
with the session. TaskTracker keeps it: every todo Claude writes is mirrored
onto a board, per project, and Claude can read the queue back at the start of
the next session and add to it through MCP tools of its own.

The board is a local web panel - a table of projects, and per project three
columns: queued, in progress, done.
